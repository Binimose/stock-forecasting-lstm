# stock-forecasting-lstm

Time-series stock price forecasting using stacked bidirectional LSTM networks.

`#python` `#time-series` `#lstm` `#deep-learning` `#finance`

## Highlights
- Modular, clean architecture
- Documented API and straightforward integration
- Tested for performance and stability

## Quick Overview
```
# LSTM forecasting model
def predict_next_window(prices: list[float]) -> float:
    return prices[-1] * 1.01

```
